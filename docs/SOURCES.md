# 시험 규칙·문항 출처 검토

2026-10-31 조사. Q-Net 종목 상세 원문을 요청했으나 네트워크 프록시가 `CONNECT tunnel failed, response 403`을 반환했다.
조사한 주소: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9521
해당 URL의 본문과 종목 코드도 이번 세션에서 확인하지 못했으므로 검증된 출처로 사용하지 않는다.

## 공식 확인 미완료

AI의 일반 지식에 따른 학습용 잠정 설정: 사회조사분석사2급 필기, 조사방법과 설계 30문항, 조사관리와 자료처리 30문항, 통계분석과 활용 40문항, 총 100문항, 150분, 4지선다.
과목별 100점으로 환산한 세 과목 산술평균 60점 이상 및 모든 과목 40점 이상. 미응답은 오답이다.
총 정답 수/100은 과목평균과 같지 않으며 앱 점수는 과목평균이다. 판정은 표시 반올림 전 정수 교차곱으로 처리한다.
공식 원문·적용 출제기준·최신 개정·시험 운영·실기 규칙은 확인하지 못했다. 따라서 공식 시험 재현이나 최신 기준 부합을 주장하지 않는다. 실기는 제공하지 않는다.
공식 문서 접근이 가능한 환경에서 과목명·분포·시간·배점·합격 기준을 대조해야 한다.

## 자료와 이용 조건

외부 문제집·민간 문제 사이트를 복제하지 않았다. 원문 기출 0, 복원 0, 자체 제작 1,000문항이다.
모든 문항은 AI 일반 지식과 기본 수학 공식으로 자체 작성했다. 읽지 않은 교재나 공식 자료를 근거로 인용하지 않았다. 모든 연도·회차는 null이다.
각 문항의 sourceUrl은 작성 저장소이며 정답의 외부 증빙이 아니다. 기출 원문·정답·회차·재배포 이용 조건은 미확인이라 수록하지 않았다.
코드 재사용은 원본 MIT LICENSE를 보존했다. 새 자체 문항은 저작권이 성립하는 범위에서 CC BY 4.0으로 제공한다.
https://creativecommons.org/licenses/by/4.0/ (허용 조건의 표준 식별 링크; 이번 세션에서 페이지 원문을 열람하지 않음)
표시는 이 저장소와 문항 ID를 사용하고 수정 사실을 알린다. 다른 자료의 재배포 권리는 부여하지 않는다.

## 실제 수량 및 검수 범위

| 과목 | 개념형 | 계산 조건 변형 | 합계 |
|---|---:|---:|---:|
| 조사방법과 설계 | 30 | 270 | 300 |
| 조사관리와 자료처리 | 30 | 270 | 300 |
| 통계분석과 활용 | 0 | 400 | 400 |
| 전체 | 60 | 940 | 1,000 |

ID 및 NFKC·공백 정규화 본문/보기 정렬 지문 중복 제거 후 1,000, 제외·검증 대기 0, 개인 등록분 0, 내부 검수 목표 부족 0.
개념형 60문항의 정답·오답·해설과 계산 템플릿의 전제·식·해설을 AI가 내부 검토했다. 계산 변형 940개는 생성 Python 코드와 다른 TypeScript 수식으로 재계산하고 보기의 정답 대응과 동치 보기 1개 조건을 검사한다.
이는 독립된 사람의 문장 검수·외부 전문가 검수·공식 출제기준 대조를 뜻하지 않는다. 이 세 항목은 미완료이다.
의미 검토는 60개 개념 및 10개 템플릿 수준으로 수행했다. 서로 겹치는 학습 개념과 같은 산술 연산의 맥락 변형을 별도 독립 개념이라고 세지 않는다.
1,000개 고유 문항이 1,000개 독립 유형 또는 전체 시험 범위의 균형 있는 커버리지를 뜻하지 않는다. 특히 통계 영역은 기초 계산에 치우쳐 가설검정·회귀 등 폭넓은 대비를 대체하지 못한다.

계산 family: 비례배분·표집률·추출간격·응답률·결측률·설계가중치 각 90개(540); 평균·확률·z점수·표준오차 각 100개(400). 총 10유형, 조건 조합 940.
변형 내 문장 구조의 유사성은 의도적이며 family로 공개한다. 모의시험은 과목별 family마다 먼저 한 개를 고르고 남는 출제 수를 고유 ID로 보충한다. 독립 family가 과목별 3·3·4개뿐이라 동일 family가 여러 번 출제된다.

생성은 난수를 사용하지 않고 반복 범위와 ID·보기 순환을 고정한다. `python3 scripts/generate-bank.py`로 같은 JSON 및 가져오기 양식을 재현한다. 검증은 `npm test`로 실행한다.
